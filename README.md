# Spinlab

Programm für Reverse-Spin-Videos aus 3D-Modellen (Windows 10/11, 64 Bit) von [The Companion Consulting](https://thecompanion.consulting/programme/spinlab/).

Aus eingebauten oder eigenen 3D-Modellen (GLB/OBJ, auch animiert) werden Punktwolken, deren Drehrichtung sich nicht eindeutig lesen lässt animiert. Mit Timeline, Farben, Hintergrundbild und nahtlosem Loop-Export (MP4, HEVC, WebM, GIF, PNG-Sequenz).

**Alle Infos und Anleitung: https://thecompanion.consulting/programme/spinlab/**

## Download

Die aktuelle Version findest du unter **[Releases](../../releases/latest)**:

- `Spinlab-Setup.exe` – Installer für Windows
- `Spinlab-Update.spinupdate` – Update-Datei, falls du Spinlab schon installiert hast (im Programm unter *Hilfe → Update installieren…*)

## Windows zeigt eine Warnung?

Spinlab ist nicht mit einem kostenpflichtigen Zertifikat signiert. Beim ersten Start meldet Windows „Der Computer wurde durch Windows geschützt“. Klicke auf **Weitere Informationen** und dann auf **Trotzdem ausführen**. Auch dein Browser kann beim Download warnen, bestätige dort „Behalten“.
